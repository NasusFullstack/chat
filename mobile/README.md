# 춥채팅 모바일 (Flutter)

PC 앱(`/`)과 **같은 저장소, 같은 버전**으로 간다. 여기 적힌 것은 "왜 이렇게 하기로 했는가"라서,
코드를 고치기 전에 읽어야 하는 내용이다. 화면 구조나 위젯 이름은 여기 안 적는다(코드가 안다).

## 왜 새로 만드나 - 포팅이 아니다

PC 앱은 PySide6(Qt)다. Qt를 폰에 올리는 길이 있기는 하지만 실험 단계이고 안드로이드만 되며
터치 느낌이 나쁘다. 그래서 **화면은 Flutter로 새로 그린다.**

다만 새로 만드는 건 화면뿐이다. 이번에 기능을 전부 서버 창구로 빼놨기 때문에:

| 무엇 | 모바일이 할 일 |
|---|---|
| 파일·사진 (`/files`) | HTTP 부르기 |
| 이모티콘 (`/files/emoji`) | HTTP 부르기 |
| 놓친 대화 (`/logs`) | HTTP 부르기 |
| 프로필·아이콘 (`/profiles`) | HTTP 부르기 |
| 전투 중계 (`/battle/ws`) | WebSocket |

**아이콘이 특히 편해졌다.** 예전엔 IRC 한 줄 512바이트 제한 때문에 300자씩 쪼개 보냈는데
(`irc_protocol.format_ctcp_avatar`), 이제 서버에 있으므로 모바일은 그 조각내기를 아예 안 만들어도 된다.

## 파이썬 코드는 라이브러리가 아니라 **명세서**다

다음 파일들은 Qt를 한 줄도 안 쓴다. 그대로 읽고 Dart로 **규칙을 옮긴다**:

| 파일 | 무엇 |
|---|---|
| `irc_protocol.py` | IRC 한 줄을 뜯고 만드는 법 |
| `chat_core/session.py` | "무슨 일이 일어났는가" 판단 |
| `chat_core/protocols/irc.py` | IRC일 때의 차이(로컬 에코 등) |
| `link_meta.py` | 주소가 안전한가, 그림인가 |
| `battle_sim.py` · `battle_ai.py` · `battle_protocol.py` | 전투 계산과 규약 |

## 지켜야 하는 것

### 1. 모르는 것은 조용히 무시한다
PC와 모바일은 **서로 다른 버전으로 같은 방에 있게 된다.** 새 기능이 한쪽에만 있을 때
상대가 죽으면 안 된다. PC 쪽이 이미 이 규칙으로 되어 있다:

- 모르는 치트 id → 무시 (`MainWindow._CHEAT_EFFECTS`)
- 표에 없는 도메인 이벤트 → 무시 (`gui/event_router.py`)
- 해석 못 한 CTCP 프레임 → **채팅으로 흘리지 말고** 버린다

모바일도 같다. 특히 마지막 것은 실제 사고 이력이 있다(잘린 base64가 채팅에 쏟아졌다).

### 2. 한도는 서버에서 받아온다
`/files`, `/logs`, `/profiles`는 전부 `limits`를 알려준다. 숫자를 코드에 박으면 서버가
바뀔 때 조용히 어긋난다. 못 받아왔을 때 쓸 **기본값**만 두고, 받아오면 그 값을 쓴다.

지금 PC 쪽도 `gui/uploader.py`만 이렇게 하고 있고 나머지는 숫자가 박혀 있다 - 모바일을
만들면서 같이 고칠 것.

### 3. 전투 계산은 **한 틱도 어긋나면 안 된다**
판은 화면 크기와 무관한 고정 좌표계(1200×800)이고, 화면은 비율만 맞춰 늘려 그린다.
오가는 것은 키 5비트(좌·우·상·하·발사)뿐이다. 그래서 폰과 PC가 같은 방에서 싸울 수 있다.

계산은 전부 정수다(1/256 단위, `isqrt`). sin/cos는 방향표를 만들 때 한 번 쓰고 버린다.
**Dart로 옮긴 뒤에는 반드시 대조 검사를 붙일 것** - 같은 입력을 파이썬과 Dart에 먹이고
매 틱 상태를 비교한다. 이게 없으면 "한 놈은 죽었다는데 다른 쪽은 안 죽었다"가 또 난다
(실제로 겪은 버그다. 각자 자기 배만 판정하도록 고쳤다 - `Battle(judged=...)`).

Dart 주의: 웹으로도 돌릴 거면 `int`가 53비트가 된다. 지금 값(좌표 최대 307,200)은 한참
아래라 안전하지만, 32비트를 넘는 비트 연산은 쓰지 말 것.

### 4. 화면은 기기 수만큼 만들지 않는다
만드는 건 **폰 레이아웃 하나**다. PC의 3열을 1열로 접는다:

| PC | 폰 |
|---|---|
| 왼쪽 채널 목록 | 왼쪽에서 밀어 여는 서랍 |
| 가운데 채팅 | 화면 전체 |
| 오른쪽 참여자 | 위 아이콘 → 아래에서 올라오는 시트 |
| 이모티콘·사진·파일 버튼 셋 | `+` 하나 → 시트 |

실제로 맞춰보는 크기는 셋이면 된다: 작은 폰(360) / 보통(390~430) / 태블릿(600+).
나머지 폭은 프레임워크가 늘린다.

**화면은 셋뿐이다**: 시작화면 → 로그인 → 채팅(+ 설정). 시작화면을 먼저 두는 이유는 PC 와
같다 - 새 버전 확인에 잠깐 걸리는데 그동안 로그인 화면이 떠 있으면 사람이 이름을 치기
시작하고 그 위로 업데이트 안내가 덮친다. 그리고 그 확인에는 **한계 시간**을 둔다
(`bootCeiling`). 플랫폼 호출 하나가 매달리는 것만으로 시작화면에 갇히면 사람 눈에는
"앱이 안 켜진다"가 되고 로그인조차 해볼 수 없다.

### 5. 홈으로 나간 뒤에도 살아 있으려면 **포그라운드 서비스가 필요하다**
안드로이드 11부터는 화면에서 사라진 앱의 프로세스를 아예 **얼린다**(cached app freezer).
소켓은 열려 있는데 우리가 움직이지 못하니 서버 PING 에 PONG 을 못 하고, 서버는 응답 없는
손님으로 보고 끊는다. 실측: 홈 버튼만 눌러도 접속이 끊겼다.

그래서 로그인에 성공하면 `ChatService`(코틀린)를 띄운다. 이 서비스는 **아무 일도 하지
않는다** - 채팅은 그대로 다트가 하고, 서비스는 프로세스가 얼지 않게 하는 역할만 한다.
소켓을 코틀린으로 옮기면 같은 판단 코드를 두 벌로 쓰게 되고 PC 와 답이 갈라진다.

지켜야 할 것:
- 서비스는 **앱이 보이는 동안** 띄운다. 안드로이드 12부터 배경에서 띄우면 거절당하므로,
  홈으로 나간 뒤에 띄우려 하면 늦는다
- "실행 중" 알림은 **숨길 수 없다**(규칙이다). 그래서 설정에서 끌 수 있게 해야 한다
- 최근 앱에서 밀어서 끄면 같이 멈춘다(`stopWithTask` + `onTaskRemoved`) - "끈 줄 알았는데
  접속되어 있는" 상태를 만들지 않는다
- `START_NOT_STICKY` - 시스템이 알아서 되살리면 안 된다

### 6. 알림은 자리가 **하나**다
말이 오는 대로 쌓으면 수다 한 번에 알림이 수십 개가 된다. 알림 번호를 하나로 고정해서
새 말이 오면 그 자리를 갈아치운다. 그리고:
- 내 말에는 안 띄운다 / 보고 있을 때는 안 띄운다 / 입장·퇴장 안내에는 안 띄운다
- 주소를 그대로 보이지 않는다 - `(사진)`, `(파일)`, `(이모티콘)`으로 바꾼다
- 판단은 `net/notifier.dart`의 **순수 함수**에 둔다. 알림은 눈으로 확인하기 번거로워서
  조건이 화면 코드에 섞이면 조용히 틀린 채로 오래 묻힌다

### 7. "무슨 프로그램을 쓰나"는 **서버에서 받아온다**
IRC 로 CTCP VERSION 을 물어보는 길은 쓰지 않는다(PC 쪽도 꺼뒀다 -
`gui/client_probe.py`의 `ASK_OVER_IRC`). 서버가 폭주로 보고 거절하고, 상대 화면에 요청이
찍히고, 다리 봇은 엉뚱한 답을 한다.

각자 프로필에 `{app, version, platform}`을 적어두고, 참여자 목록을 받을 때 어차피 하는
프로필 조회로 같이 읽는다(`/profiles` 1.1.0 이상). **받은 글자를 그대로 그리지 않는다** -
화면에 뜨는 값이라 아무 글자나 받으면 남이 내 화면에 글을 쓰는 길이 된다.

### 8. 프로필을 올릴 때 **안 보낼 칸은 보내지 않는다**
모바일에는 아이콘 편집기가 없어서 "나는 춥채팅 모바일"만 올린다. 그때 빈 아이콘을 같이
보내면 그 사람이 PC 에서 정해둔 얼굴이 서버에서 지워진다(같은 닉네임이면 같은 자리다).
서버는 안 온 칸을 그대로 둔다.

## 버전은 하나다

`version.py`의 `APP_VERSION`이 출처이고 `pubspec.yaml`이 같은 값을 갖는다.
`tests/test_version_sync.py`가 이걸 강제한다 - 어긋나면 실패한다.

CHANGELOG도 하나다. "PC만 바뀐 항목"이어도 같은 문서에 적는다 - 사용자는 앱이 둘이라는
걸 신경 쓰고 싶지 않다.

## 기기에 적어두는 것

| 무엇 | 어디 | 왜 |
|---|---|---|
| 알림·접속 유지 설정 | `prefs.dart` | PC 의 `app_prefs.py`와 같은 자리 |
| 이름·서버·자동 들어가기 | `login_store.dart` | 폰에서 글자 치는 건 번거롭다 |
| 들어갔던 채널 | `login_store.dart` (서버+이름별) | PC 도 같다(`channel_store.py`) |
| 믿기로 한 인증서 지문 | `net/trusted_certs.dart` | 개인 서버는 자체 서명이다 |

**비밀번호는 적지 않는다.** 우리 서버는 접속 비밀번호를 쓰지 않고, 평문으로 기기에 남길
이유가 없다.

채널 목록을 적는 일은 **차례대로** 한다. 한꺼번에 던지면 끝나는 순서가 뒤바뀌어 옛 목록이
나중에 덮어쓴다(실측: 들어가기 두 번을 연달아 했을 때 두 번째가 사라졌다). 그리고 지난
채널에 다시 들어가는 **동안에는 적지 않는다** - 도중에 앱이 꺼지면 아직 못 들어간 방들이
통째로 사라진다.

## 아직 안 정한 것

- **전투(배틀크루저).** 아직 모바일에 없다. 계산(`battle_sim.py`)과 규약
  (`battle_protocol.py`)을 Dart 로 옮기고 **파이썬과 매 틱 대조**해야 한다(위 3번).
  조작은 가상 조이스틱으로 바꾼다
- **앱이 완전히 꺼져 있을 때 알림.** 지금은 포그라운드 서비스로 "켜둔 동안"을 지킨다.
  완전히 끈 상태까지 받으려면 FCM 이 필요하고, 누군가 IRC 에 붙어 있다가 밀어줘야 한다 -
  jsserv 가 그 역할을 하는 구조가 자연스러운데 아직 안 만들었다
- **아이콘(프로필 사진) 바꾸기** - 지금은 PC 에서만 바꾼다. 폰에서는 받아서 보여주기만 한다
