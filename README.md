# 친구 채팅 (IRC 스타일 TUI 채팅 프로그램)

## 🚀 제일 쉬운 실행법 (윈도우, 더블클릭)

Python만 미리 설치되어 있으면 (https://www.python.org/downloads/ 에서 설치, "Add Python to PATH" 꼭 체크) 나머지는 자동입니다.

- **서버를 켤 대표 한 명**: `서버_실행.bat` 더블클릭
  - 라이브러리 자동 설치 + 서버 실행 + 본인 IP 주소 화면에 표시됨
  - 이 창은 계속 켜두어야 함 (닫으면 서버 종료)
- **참여하는 친구들 각자**: `채팅_시작.bat` 더블클릭
  - 라이브러리 자동 설치 후, 서버 주소 입력하라고 물어봄 → 대표가 알려준 IP 입력 → Enter
  - 이후 화면 안내에 따라 회원가입 → 로그인 → 채널 생성/입장 → 채팅

같은 컴퓨터에서 테스트만 해볼 거면 `채팅_시작.bat` 실행할 때 서버 주소 물어보는 곳에서 그냥 Enter만 치면 됩니다 (127.0.0.1로 자동 연결).

## 💿 친구들 컴퓨터에 파이썬 없이 실행하고 싶다면 (exe로 배포)

친구들이 파이썬 설치 없이 그냥 exe 더블클릭만으로 쓰게 하려면:

1. **준성님 컴퓨터에서 딱 한 번만**: `exe로_빌드하기.bat` 더블클릭
   - 준성님 컴퓨터에는 Python이 있어야 빌드 가능 (친구들 컴퓨터는 필요 없음)
   - 자동으로 `dist` 폴더 안에 두 개의 exe 생성됨:
     - `FriendChat.exe` → 친구들에게 이 파일만 나눠주면 됨
     - `FriendChat_Server.exe` → 대표(서버 켜는 사람)가 실행

2. 이후 친구들은 `FriendChat.exe` 더블클릭만 하면 파이썬 설치 없이 바로 실행됩니다.

**참고**: exe는 빌드한 컴퓨터의 운영체제 기준으로 만들어져요. Windows에서 빌드하면 Windows용 exe가 나옵니다. 처음 빌드할 때 파일 용량이 좀 크고(수십 MB) 시간이 몇 분 걸릴 수 있어요.

## 🌐 내 컴퓨터에 파이썬 자체를 아예 설치하기 싫다면 (GitHub Actions로 빌드)

준성님 컴퓨터에 파이썬을 전혀 설치하지 않고도 exe를 만들 수 있어요. GitHub의 온라인 서버에서 대신 빌드해줍니다.

**1단계 - GitHub 계정 생성**: https://github.com 에서 무료 가입 (이미 있으면 생략)

**2단계 - 새 저장소(repository) 만들기**
- GitHub 로그인 후 오른쪽 위 `+` → `New repository`
- 이름 아무거나 (예: `friend-chat`), Public/Private 아무거나 선택 → `Create repository`

**3단계 - 파일 업로드**
- 만들어진 저장소 페이지에서 `uploading an existing file` 클릭
- `chatapp` 폴더 안의 파일/폴더를 전부 끌어다 놓기 (`.github` 폴더 포함해서 전부!)
- 아래 `Commit changes` 클릭

**4단계 - 자동 빌드 확인**
- 저장소 페이지 상단 `Actions` 탭 클릭
- "Build Windows EXE" 라는 작업이 자동으로 실행 중일 거예요 (2~3분 정도 소요)
- 초록색 체크 표시가 뜨면 완료

**5단계 - exe 다운로드**
- 완료된 작업(Build Windows EXE) 클릭 → 페이지 아래쪽 `Artifacts` 부분에서
  `FriendChat-Windows-EXE` 클릭하면 zip으로 다운로드됨
- 압축 풀면 `FriendChat.exe`, `FriendChat_Server.exe` 들어있음

이후 코드를 수정하고 다시 업로드(commit)할 때마다 자동으로 새 exe가 만들어져요.

---


친구들끼리 쓰는 간단한 실시간 채팅 프로그램입니다.
- 서버: Python asyncio 기반, IRC 개념(계정 / 채널 / 채널 비밀번호)을 JSON 프로토콜로 단순화 구현
- 클라이언트: 터미널 TUI (textual 라이브러리) — 로그인/회원가입 → 채널 입장/생성 → 채팅

## 설치

```bash
pip install -r requirements.txt
```

## 1. 서버 실행 (한 명이 대표로 실행하면 됨)

```bash
cd server
python server.py 6667
```

- `6667`은 포트 번호. 원하는 포트로 바꿔도 됩니다.
- 이 서버를 계속 켜둘 컴퓨터 또는 클라우드 VM에서 실행하세요.
- 데이터(계정/채널 정보)는 `server_data.json`에 저장됩니다. (비밀번호는 평문이 아니라 salt+sha256 해시로 저장)
- 방화벽/공유기에서 해당 포트를 열어줘야 외부 친구들이 접속 가능합니다.

## 2. 클라이언트 실행 (각자 실행)

```bash
cd client
python tui_client.py <서버주소> <포트>
```

예:
```bash
python tui_client.py 123.45.67.89 6667
```

로컬 테스트라면:
```bash
python tui_client.py 127.0.0.1 6667
```

## 사용 흐름

1. **로그인 화면**: 서버 주소/포트 확인 후, 아이디·비밀번호 입력
   - 처음이면 "회원가입" 먼저 누르고, 이후 "로그인"
2. **채널 화면**: 채널명(예: `#친구들`)과 원하면 채널 비밀번호 입력
   - 새 채팅방이면 "새 채널 만들기" → 이후 "입장"
   - 이미 있는 채팅방이면 바로 "입장"
3. **채팅 화면**: 하단 입력창에 메시지 입력 후 Enter, 오른쪽에 현재 참여자 목록 표시

## 현재 구현된 것

- 계정 회원가입/로그인 (비밀번호 해시 저장)
- 채널 생성 + 채널 비밀번호(선택)
- 채널 입장 시 비밀번호 검증
- 실시간 메시지 송수신
- 입장/퇴장 알림, 참여자 목록 실시간 갱신

## 아직 없는 것 (다음 단계로 확장 가능)

- 이미지/파일 전송
- 여러 채널 동시 참여 / 채널 전환 UI
- 메시지 기록 저장 (재접속 시 이전 대화 불러오기)
- TLS 암호화 (현재는 평문 통신 — 인터넷에 공개로 띄울 거면 TLS 추가 권장)
- 웹 클라이언트 (원하면 같은 서버 프로토콜에 붙는 웹 UI도 추가 제작 가능)

## 서버를 실제로 계속 켜두려면

- Railway / Fly.io / 오라클 클라우드 프리티어 등에 배포
- 또는 집 컴퓨터/라즈베리파이에서 24시간 실행 + 포트포워딩
