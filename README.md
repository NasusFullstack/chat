# 친구 채팅 (IRC 스타일 채팅 프로그램)

친구들끼리 쓰는 간단한 실시간 채팅 프로그램입니다.
- **서버**: Python asyncio 기반, IRC 개념(계정 / 채널 / 채널 비밀번호)을 JSON 프로토콜로 단순화 구현, TLS 암호화 적용
- **클라이언트**: GUI / TUI / CLI 세 가지 버전 제공 (아래 비교 참고)

---

## 🖥️ 클라이언트 버전 비교 — 뭘 써야 하나요?

| | GUI (`gui_client.py`) | TUI (`tui_client.py`) | CLI (`cli_client.py`) |
|---|---|---|---|
| 모습 | 진짜 창 프로그램 | 터미널 안의 박스형 화면 | 터미널, 텍스트만 |
| 한글 쌍자음(ㄲㄸㅃㅆㅉ) 입력 | ✅ 문제없음 | ⚠️ 조합 중 날아갈 수 있음 | ✅ 문제없음 |
| 인증서 경로 입력 | 파일 선택 버튼으로 클릭만 | 직접 붙여넣기 (자동 감지 지원) | 직접 붙여넣기 (자동 감지 지원) |
| 추천 대상 | **대부분의 사람 (기본 추천)** | 터미널 좋아하는 사람 | 가장 가벼운 걸 원하는 사람 |

**결론: 특별한 이유가 없으면 GUI(`FriendChat_GUI.exe`) 사용을 추천합니다.** TUI는 한글 입력 중 Shift를 눌러 쌍자음/특수기호를 만들 때 조합 중이던 글자가 사라지는 문제가 있는데, 이는 터미널 프로그램들의 구조적인 한계라 완전히 고치기 어렵습니다.

---

## 🚀 제일 쉬운 실행법 (윈도우, 더블클릭)

Python만 미리 설치되어 있으면 (https://www.python.org/downloads/ 에서 설치, "Add Python to PATH" 꼭 체크) 나머지는 자동입니다.

- **서버를 켤 대표 한 명**: `서버_실행.bat` 더블클릭
  - 라이브러리 자동 설치 + 서버 실행 + 본인 IP 주소 화면에 표시됨
  - 처음 실행 시 같은 폴더에 `cert.pem`, `key.pem`이 자동 생성됨
  - `key.pem`은 절대 남에게 공유하지 말 것 (서버만 보관)
  - `cert.pem`은 참여자들에게 IP 주소와 함께 전달할 것
  - 이 창은 계속 켜두어야 함 (닫으면 서버 종료)
- **참여하는 친구들 각자**: `채팅_시작.bat` 더블클릭 (TUI 버전 실행)
  - 라이브러리 자동 설치 후, 서버 주소 입력하라고 물어봄 → 대표가 알려준 IP 입력 → Enter
  - 이후 화면 안내에 따라 회원가입 → 로그인 → 채널 생성/입장 → 채팅

같은 컴퓨터에서 테스트만 해볼 거면 서버 주소 물어보는 곳에서 그냥 Enter만 치면 됩니다 (127.0.0.1로 자동 연결).

## 💿 친구들 컴퓨터에 파이썬 없이 실행하고 싶다면 (exe로 배포)

1. **본인 컴퓨터에서 딱 한 번만**: `exe로_빌드하기.bat` 더블클릭
   - 본인 컴퓨터에는 Python이 있어야 빌드 가능 (친구들 컴퓨터는 필요 없음)
   - `dist` 폴더 안에 exe들이 생성됨:
     - `FriendChat_GUI.exe` → **추천**, 창 프로그램, 한글 입력 문제없음
     - `FriendChat.exe` → TUI 버전
     - `FriendChat_CLI.exe` → CLI 버전
     - `FriendChat_Server.exe` → 대표(서버 켜는 사람)가 실행

2. 친구들은 원하는 클라이언트 exe만 받아서 더블클릭하면 파이썬 설치 없이 바로 실행됩니다.

**참고**: exe는 빌드한 컴퓨터의 운영체제 기준으로 만들어집니다. Windows에서 빌드하면 Windows용 exe가 나옵니다. GUI 버전은 Qt 라이브러리가 포함돼서 파일 용량이 좀 큽니다 (100MB 이상 가능).

## 🌐 내 컴퓨터에 파이썬 자체를 설치하기 싫다면 (GitHub Actions로 빌드)

GitHub의 온라인 서버에서 대신 빌드해줍니다. 이 저장소에 이미 `.github/workflows/build-exe.yml`이 포함돼 있어서, 코드를 GitHub에 올리기만 하면 자동으로 빌드됩니다.

1. 저장소에 파일 전부 업로드 (`Add file → Upload files`), `Commit changes`
2. 저장소 상단 **`Actions`** 탭 → "Build Windows EXE" 자동 실행 (5~10분 소요, GUI 빌드 포함이라 예전보다 조금 걸림)
3. 완료되면 **`Artifacts`**에서 두 개 다운로드 가능:
   - `FriendChat-Windows` → GUI/TUI/CLI/서버 exe 전부 (Windows용)
   - `FriendChat-Server-Linux` → 리눅스 서버용 실행 파일

코드를 수정하고 다시 커밋할 때마다 자동으로 새로 빌드됩니다.

## 🐧 리눅스 서버에서 직접 실행하고 싶다면 (venv)

파이썬 코드 그대로 실행해도 됩니다. `run_server.sh`를 함께 받아서:

```bash
chmod +x run_server.sh   # 최초 1회만
./run_server.sh 6667     # 원하는 포트 번호
```

venv 자동 생성 + 라이브러리 설치 + 서버 실행까지 한 번에 처리됩니다. 다음에 실행할 땐 venv가 이미 있어서 바로 서버가 뜹니다.

계속 켜두려면:
```bash
nohup ./run_server.sh 6667 > server.log 2>&1 &
```

## 🔒 보안 (TLS 암호화)

- 서버 실행 시 자체 서명 인증서(`cert.pem`, `key.pem`)가 자동 생성됩니다.
- 클라이언트가 접속할 때 이 `cert.pem`을 지정하면, 통신이 암호화되는 것은 물론 **"진짜 이 서버가 맞는지" 신원 검증**까지 이루어집니다.
- `cert.pem` 없이 접속해도 통신 자체는 암호화되지만(도청 방지), 서버 신원 검증은 생략됩니다.
- **`key.pem`은 서버만 갖고 있어야 하며 절대 공유하면 안 됩니다.**

---

## 사용 흐름

1. **로그인 화면**: 서버 주소/포트 입력, (선택) `cert.pem` 지정 → 아이디·비밀번호 입력
   - 처음이면 "회원가입" 먼저, 이후 "로그인"
2. **채널 화면**: 채널명(예: `#친구들`)과 원하면 채널 비밀번호 입력
   - 새 채팅방이면 "새 채널 만들기" → 이후 "입장"
   - 이미 있는 채팅방이면 바로 "입장"
3. **채팅 화면**: 메시지 입력 후 Enter, 참여자 목록 실시간 표시

## 현재 구현된 것

- 계정 회원가입/로그인 (비밀번호 salt+sha256 해시 저장)
- 채널 생성 + 채널 비밀번호(선택)
- 채널 입장 시 비밀번호 검증
- 실시간 메시지 송수신, 입장/퇴장 알림, 참여자 목록 실시간 갱신
- TLS 암호화 + 서버 신원 검증
- GUI / TUI / CLI 세 가지 클라이언트

## 문제 해결 (Troubleshooting)

- **"연결이 거부되었습니다" / Connection refused**: 서버가 꺼져 있거나 포트 번호가 다른 경우가 대부분입니다. 서버 쪽에서 정확한 포트로 실행 중인지 확인하세요.
- **cert.pem 관련 오류**: GUI는 "찾아보기" 버튼으로 직접 선택하는 걸 추천합니다. TUI/CLI는 exe와 같은 폴더에 `cert.pem`을 두면 자동으로 인식합니다.
- **배치 파일 실행 시 한글이 깨지며 오류**: 배치 파일이 UTF-8(BOM 포함)로 저장돼 있는지 확인하세요.
- **exe 실행 시 한글 입력 중 글자가 사라짐 (TUI/CLI)**: 터미널 프로그램의 구조적 한계입니다. GUI 버전을 사용하세요.
